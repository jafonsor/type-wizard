# Word list sources

`words.txt` is a PLACEHOLDER: 400 pronounceable, made-up lowercase `[a-z]{3,8}`
strings, one per line, sorted by length. It exists so the embed and the word
count can be built and checked. The dictionary pipeline ticket replaces it
with the real SCOWL-derived list (spec section 10) and rewrites this file
with SCOWL's copyright text.
